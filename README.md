# Path Finding
# Geometry Dash Physics Simulator

A fork of camila314/pathfinder with a wider simulator, a rewritten search and a
working Android export. This code is not currently licensed for redistribution.

## Notes

1. Y positions are slightly off because in the real gd, they are offest by 105
2. Robot, spider, swing and dash orb constants are derived rather than dumped
   from the game, so they are approximate; every macro is replay-verified.
